## 🛠️ Tech Stack

Saat ini sistem web portofolio ini terintegrasi langsung untuk memuat konten dari desain Framer kami. 

- **ReactJS** - Frontend framework
- **Framer** - Web design and hosting untuk konten utama
- **Tailwind CSS** - Utility-first CSS framework (untuk kustomisasi jika diperlukan di masa mendatang)

## 🏃‍♂️ Getting Started

Ikuti langkah berikut jika ingin menjalankan wrapper lokal (hanya menampilkan desain live Framer secara full screen di server lokal):

### 1. Clone the Repository

```bash
git clone https://github.com/rusdirmdhn/Portofolio-Editor-Rusdi.git
cd Portofolio-Editor-Rusdi
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Development Server

```bash
npm run dev
```

### 4. Open in Browser

Akses aplikasi melalui tautan yang ditampilkan di terminal (biasanya `http://localhost:5173`).
